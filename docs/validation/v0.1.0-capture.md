## Compatibility and limitations

This candidate supports the OpenGGF 0.6 schema-v5 line from extraction base
`88530afdf331fb152f88a4d14adb8f93f2299ff6` through the 0.6 release. Legacy
trace envelopes are unsupported. Exact official BizHawk 2.11 is required;
2.11.1 and later are not accepted. The release is source-only and carries no
emulator, build, ROM, movie, fixture, or capture payload. Native release
captures were validated on Linux x86_64/Mono; Windows launchers remain
source-contract tested rather than release-capture tested. OpenGGF integration
is optional and pins an immutable TraceChaser commit rather than a branch.
